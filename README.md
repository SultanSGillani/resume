# Resume Website

Modern responsive resume website built with React, TypeScript, and Vite.

## Tech Stack

- React 18
- TypeScript
- Vite
- JSON-driven content from `resume.json`

## Commands

- `npm install` - install dependencies
- `npm run dev` - start local dev server
- `npm run build` - type-check and produce production build
- `npm run preview` - preview production build locally

## Content Updates

Edit `resume.json` to update profile, experience, skills, and credentials. The UI reads this data directly.
